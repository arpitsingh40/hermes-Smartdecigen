# V147 · CONTINUOUS DISCOVERY HABITS — Teresa Torres
Tier 3 · Product · Tree Memory

## ROOT
Product discovery shouldn't be a phase before delivery — it should be continuous. Torres provides the most practical, actionable framework for product trios (PM, designer, engineer) to talk to customers every week, generate and test assumptions, and make evidence-based decisions. The key insight: opportunity mapping (mapping the customer opportunity space) replaces feature backlogs with structured problem spaces. A good opportunity is a customer need, pain point, or desire — not a solution idea.

## TRUNK
Core practices: (1) Opportunity Solution Tree: start with a desired outcome, map opportunities (customer needs), generate solutions, run experiments. (2) Continuous interviewing: talk to customers weekly — not during "research phases." (3) Assumption testing: every idea rests on assumptions (desirability, feasibility, viability). Test the riskiest assumptions first, with the cheapest experiment possible. (4) The Product Trio: PM + designer + engineer collaborate on discovery, not PM alone. (5) Decision-making: evaluate evidence, not opinions. The key shift: from "what should we build next?" to "which opportunity should we address next?"

## FRUIT
- WHEN discovery feels like a phase → APPLY continuous interview habit: schedule one customer conversation per week, every week.
- WHEN prioritizing → APPLY opportunity mapping: organize ideas by customer opportunity, not by who requested it.

## SEEDS
- "Discovery is not a phase — it's a weekly habit."
- "Map opportunities, not features. Solve problems, not backlogs."
- "Test the riskiest assumption first. With the cheapest experiment possible."
