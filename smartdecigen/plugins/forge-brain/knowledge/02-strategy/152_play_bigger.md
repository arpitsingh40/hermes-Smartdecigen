# V152 · PLAY BIGGER — Al Ramadan, Dave Peterson, Christopher Lochhead, Kevin Maney
Tier 3 · Strategy · Tree Memory

## ROOT
The greatest value creation comes not from building a better product within an existing category — but from designing and dominating a new category. Play Bigger's research: category kings (companies that define, develop, and dominate a new category) capture 76% of the category's total market cap. The rest split 24%. Category design is the ultimate strategic move.

## TRUNK
Category design has 3 parts: (1) Problem — name a problem so big and urgent that it demands a new category. Frame it using a "lightning strike" (a compelling narrative that makes the old way look broken). (2) Solution — design the product AND the category simultaneously. The category POV (point of view) is as important as the product itself. (3) Mobilization — build an ecosystem: analysts, press, influencers, customers, partners — all telling the same category story. The playbook: data → insight → category POV → mobilization → domination. Category design is a CEO-level function, not a marketing function.

## FRUIT
- WHEN positioning feels inadequate → APPLY category design: are you competing in someone else's category or designing your own?
- WHEN messaging doesn't land → APPLY the lightning strike: what's the burning problem that demands a new way?
