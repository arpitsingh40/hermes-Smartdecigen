# V102 · DEEP WORK — Cal Newport
Tier 3 · Mindset · Tree Memory

## ROOT
Deep work: professional activities performed in a state of distraction-free concentration that push cognitive capabilities to their limit. These efforts create new value, improve skill, and are hard to replicate. Shallow work: logistical, non-cognitively demanding tasks performed while distracted — these don't create much value and are easy to replicate. In an economy where attention is fragmented, the ability to do deep work is becoming the single biggest competitive advantage.

## TRUNK
Four rules: (1) Work deeply — schedule deep work blocks. Four philosophies: monastic (eliminate all shallow), bimodal (deep seasons), rhythmic (daily habit), journalistic (fit it in whenever). (2) Embrace boredom — train your brain to resist distraction. Don't reach for your phone in every spare moment. (3) Quit social media — apply the "craftsman approach": only use a tool if its benefits substantially outweigh its costs. Not "what can this tool do?" but "does this tool support my core goals?" (4) Drain the shallows — schedule every minute. Batch shallow tasks. Set hard end times. Ask "how long would it take to complete this in a state of uninterrupted focus?"

## FRUIT
- WHEN productivity feels low → APPLY the distraction audit: how many times do you check email/slack/phone per hour? Reduce to 2-3 fixed windows.
- WHEN calendar is fragmented → APPLY deep work blocks: 2-3 hour uninterrupted blocks, 3-4x per week.
- WHEN considering a new tool → APPLY the craftsman approach: does it support your core goals? If not, skip.

## SEEDS
- "Deep work creates value. Shallow work does not. Guard the deep."
- "Two 3-hour deep work sessions per week produce more than 40 distracted hours."
- "Embrace boredom. Don't reach for distraction in every spare moment."
- "Schedule every minute of your day. Even leisure."

## GRAFTS
- → Essentialism: the prioritization that protects deep work time.
- → The ONE Thing: the focusing question that makes deep work productive.
