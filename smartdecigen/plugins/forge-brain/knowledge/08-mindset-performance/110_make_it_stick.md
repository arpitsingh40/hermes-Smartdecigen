# V110 · MAKE IT STICK — Peter C. Brown, Henry L. Roediger, Mark A. McDaniel
Tier 3 · Mindset · Tree Memory

## ROOT
Most common learning practices — re-reading, massed practice (cramming), highlighting — are nearly useless. The cognitive science is clear: the most effective learning strategies are retrieval practice (testing yourself), spaced repetition (spread practice over time), interleaving (mix related topics instead of blocking them), elaboration (explain it in your own words), and generation (try to solve before being shown the solution). The harder the retrieval, the stronger the learning.

## TRUNK
Key strategies: (1) Retrieval practice — actively recall from memory. This is 2-3x more effective than re-reading. Low-stakes quizzes, flashcards, closing the book and summarizing. (2) Spaced repetition — space practice sessions over increasing intervals. Cramming works for the next day's test; it fails for long-term retention. (3) Interleaving — mix topics within a study session. Block practice (all topic A, then all topic B) feels easier but produces worse transfer. Interleaving feels harder but produces deeper learning. (4) Elaboration — connect new knowledge to existing knowledge. "How does this relate to what I already know?" (5) Generation — try to answer before being shown the solution. The struggle itself strengthens learning. Illusions of knowing: fluency (easy re-reading feels like learning), familiarity (recognizing feels like knowing).

## FRUIT
- WHEN studying → APPLY retrieval: close the book, try to recall. Don't re-read.
- WHEN designing training → APPLY spaced interleaved practice: spread sessions, mix topics, test frequently.
- WHEN evaluating team learning → APPLY the fluency test: can they explain it without notes? Re-reading fluency ≠ understanding.
